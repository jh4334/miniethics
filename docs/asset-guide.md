# 프로덕션 에셋 가이드

캐릭터 14종, 배경 14종, 앱 아이콘은 완성된 프로덕션 PNG입니다. 교체가 필요한
별도 에셋 작업에서만 `docs/ASSET_TASK.md`의 경로·스타일·검증·저장소 반영 절차를 따릅니다.

## 교체 방법 (코드 수정 불필요!)

1. `public/assets/` 폴더에서 바꾸고 싶은 캐릭터의 폴더를 찾는다
2. 새 그림을 **같은 이름의 PNG**로 넣는다 (예: `hero.svg` 옆에 `hero.png`)
3. 캐릭터는 WebP → PNG → SVG, 배경은 WebP → PNG 순서로 로드됩니다. WebP는 선택 최적화본이고 PNG가 기준 원본입니다.
4. `npm run test:contracts && npm run build`로 경로·크기·알파·빌드를 확인합니다.

> 캐릭터는 1024×1024 투명 RGBA, 배경은 1280×800 불투명 RGB PNG를 유지합니다.

코덱스 같은 에이전트에게 시킬 때는 [`docs/ASSET_TASK.md`](ASSET_TASK.md)를 읽게 하세요.
경로·파일명·스타일·검증 방법까지 전부 적혀 있습니다.

## 에셋 규격과 목록

| 파일 | 용도 | 등장 위치 | 권장 크기 |
|---|---|---|---|
| `assets/common/hero.png`, `eti.png` | 주인공·가이드 | 타이틀, 월드맵, 스토리 | 1024×1024 RGBA |
| `assets/game01/cookbot.png` ~ `game03/thief.png` | 1~3차시 캐릭터 | 스토리·게임 | 1024×1024 RGBA |
| `assets/game04/char04.png` ~ `game12/char12.png` | 4~12차시 캐릭터 | 스토리·게임 | 1024×1024 RGBA |
| `assets/bg/title.png`, `worldmap.png` | 타이틀·월드맵 배경 | 씬 배경 | 1280×800 RGB |
| `assets/game01/bg.png` ~ `game12/bg.png` | 1~12차시 배경 | 스토리 배경 | 1280×800 RGB |
| `icons/icon.svg` `icon-192.png` `icon-512.png` | 앱 아이콘 (홈 화면 추가 시) | 브라우저·홈 화면 | 512×512 |

SVG 캐릭터 파일은 PNG/WebP 로딩 실패 시 사용하는 의도된 폴백이므로 삭제하지 않습니다.
에셋 PR은 프로그램 리팩터링과 분리하고 `public/assets/**` 외 코드 경로를 함께 바꾸지 않습니다.

## 효과음 교체 (선택)

현재 효과음은 코드로 합성한 소리입니다(`src/core/audio.ts`).
mp3 파일로 바꾸고 싶으면 `public/assets/sounds/` 폴더를 만들어 파일을 넣고
`audio.ts`의 각 함수를 `new Audio('./assets/sounds/xxx.mp3').play()` 형태로 수정하면 됩니다.
