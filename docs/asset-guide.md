# 에셋 교체 가이드 (GPT로 만든 그림으로 바꾸기)

지금 들어 있는 그림은 전부 **플레이스홀더(임시 그림)** 입니다.
GPT 등으로 만든 귀여운 그림을 **같은 파일명으로 덮어쓰기만 하면** 게임에 바로 반영됩니다.

## 교체 방법 (코드 수정 불필요!)

1. `public/assets/` 폴더에서 바꾸고 싶은 캐릭터의 폴더를 찾는다
2. 새 그림을 **같은 이름의 PNG**로 넣는다 (예: `hero.svg` 옆에 `hero.png`)
3. 끝! **PNG가 있으면 자동으로 PNG를 사용**하고, 없으면 기존 SVG 플레이스홀더를 사용합니다

> 필수: 배경이 **투명한** PNG(1024×1024 권장). 흰 배경이면 게임 화면에서 티가 납니다.

코덱스 같은 에이전트에게 시킬 때는 [`docs/ASSET_TASK.md`](ASSET_TASK.md)를 읽게 하세요.
경로·파일명·스타일·검증 방법까지 전부 적혀 있습니다.

## GPT 이미지 생성 프롬프트 예시

캐릭터마다 아래 틀을 활용해 보세요. **일관된 스타일**을 위해 같은 문구를 유지하고 캐릭터 설명만 바꾸는 것이 좋습니다.

```
모바일 캐주얼 RPG 게임 캐릭터 일러스트 (쿠키런 킹덤·브롤스타즈 느낌).
타깃은 초등 5~6학년 — 귀엽지만 유아용은 절대 아님.
채도 높은 선명한 색, 강한 명암 대비, 셀 셰이딩, 두꺼운 다크 외곽선,
역동적인 포즈와 개성 있는 표정, 정면 전신, 투명 배경.
금지: 아기 볼터치, 반짝이 왕눈이, 파스텔 워싱, 유아 그림책 느낌.

캐릭터: (아래에서 선택)
- 주인공: 11~12세 사이버 요원, 고글을 머리에 올림, 보라 재킷+노랑 포인트, 자신감 있는 포즈
- 에티: 매끈한 하늘색 호버 가이드 로봇, 노란 안테나, 화면 얼굴에 민트 스마일 눈
- 쿡봇: 요리사 모자의 열정 셰프 로봇, 뒤집개를 휘두르는 포즈, 바퀴 다리
- 냠봇: 학사모를 쓴 민트색 과일박사 로봇, 신나서 입을 크게 벌린 코믹한 표정
- 정보도둑: 능글맞게 웃는 보라색 그림자 몬스터 악당, 도둑 안대, 정보 카드 자루를 둘러멤
```

## 효과음 교체 (선택)

현재 효과음은 코드로 합성한 소리입니다(`src/core/audio.ts`).
mp3 파일로 바꾸고 싶으면 `public/assets/sounds/` 폴더를 만들어 파일을 넣고
`audio.ts`의 각 함수를 `new Audio('./assets/sounds/xxx.mp3').play()` 형태로 수정하면 됩니다.
