# 🎨 GPT 이미지 생성 프롬프트 모음 (AI 윤리 미니게임 천국)

이 문서는 ChatGPT(이미지 생성)에 **그대로 복사해서 붙여넣을 수 있는 프롬프트**를 모아둔 것입니다.
순서대로 진행하면 스타일이 통일된 에셋 세트가 나옵니다.

---

## 0. 시작 전에 꼭 읽기 (작업 요령)

1. **한 대화에서 끝까지 진행**하세요. 새 대화를 열면 스타일이 달라집니다. 대화 첫머리에 아래 "①스타일 가이드" 프롬프트를 먼저 보내고, 이후 모든 요청은 "위 스타일 가이드를 그대로 유지해서"로 시작하세요.
2. **스프라이트 시트(그리드) 방식**을 추천합니다. 여러 개를 한 장에 격자로 뽑으면 스타일이 자동으로 통일되고, 잘라 쓰기 쉽습니다. (예: "4×4 격자, 각 칸에 하나씩, 칸 사이 여백 넉넉히")
3. **투명 배경(PNG)** 을 매번 명시하세요. 안 되면 "완전한 흰색 배경(#FFFFFF), 그림자 없이"로 받아서 배경 제거 도구를 쓰세요.
4. **이미지 안에 글자는 넣지 마세요.** 라벨은 앱이 코드로 그립니다. (프롬프트에 "no text, no letters" 포함)
5. 마음에 드는 결과가 나오면 **"이 캐릭터를 기준(reference)으로 고정"** 하고, 이후 표정/포즈 변형을 요청하세요.
6. 파일명은 아래 표의 **파일명 규약**대로 저장하면 나중에 코드에 연결하기 쉽습니다.

### 앱의 색상 팔레트 (css/style.css 기준)

| 이름 | HEX | 용도 |
|---|---|---|
| 하늘 | `#BFE7FF` / `#7EC8FF` | 배경, 메인 톤 |
| 크림 | `#FFF9EC` | 배경 하단, 카드 |
| 잉크(글자) | `#3A3A55` | 윤곽선, 눈 |
| 핑크 | `#FF8FB2` | 볼터치, 강조 |
| 노랑 | `#FFD66B` | 버튼, 별, 배지 |
| 초록 | `#7DDBA3` | 정답, 좋은 것 |
| 빨강 | `#FF7D7D` | 오답, 위험 |
| 보라 | `#B39DFF` | 필터버블, AI 게이지 |
| 주황 | `#FFAB6B` | 타이머 |
| 파랑 | `#6BB8FF` | 포인트 색 |

## ① 스타일 가이드 (대화 첫 번째 메시지로 보내기)

```
지금부터 초등학교 5~6학년용 교육 게임 앱 "AI 윤리 미니게임 천국"의 일러스트를 함께 만들 거야.
아래 스타일 가이드를 이 대화 내내 그대로 유지해 줘.

[스타일 가이드]
- 장르: 귀여운 카와이(kawaii) 플랫 벡터 일러스트, 미니게임천국·쿠키런 느낌의 밝고 통통한 캐릭터
- 선: 짙은 남색(#3A3A55)의 부드럽고 두꺼운 외곽선, 둥근 모서리
- 색: 파스텔 팔레트 — 하늘색 #7EC8FF, 노랑 #FFD66B, 핑크 #FF8FB2, 민트 #7DDBA3, 보라 #B39DFF, 크림 #FFF9EC
- 명암: 셀 셰이딩 1단계만, 부드러운 하이라이트, 복잡한 그라데이션 없음
- 표정: 큰 눈, 작은 입, 볼터치 — 어린이가 보고 웃을 수 있는 순한 인상
- 금지: 사실적 렌더링, 무서운 요소, 이미지 안의 글자/숫자, 워터마크
- 출력: 정사각형, 투명 배경 PNG, 그림자 없이 대상만 크게

이해했으면 "준비됐어요"라고만 답해 줘.
```

## ② 마스코트 로봇 (P1 · 가장 중요)

앱 전체(타이틀, 2·3·9차시 로봇, 결과 화면)에 쓰이는 주인공입니다.

### ②-1 기본 디자인
```
위 스타일 가이드를 그대로 유지해서, 앱의 마스코트 로봇을 디자인해 줘.
- 둥글고 통통한 몸, 머리 위에 노란 구슬 안테나 하나, 하늘색(#7EC8FF) 몸통에 크림색 얼굴판
- 커다란 둥근 눈, 볼터치, 짧은 팔다리, 가슴에 작은 하트 모양 불빛
- 정면, 살짝 손 흔드는 포즈, 친근하고 똑똑해 보이는 인상
- 투명 배경, 정사각형, 캐릭터가 화면의 80%를 차지하게
```

### ②-2 표정 세트 (스프라이트 시트)
```
방금 만든 마스코트 로봇을 기준 캐릭터로 고정하고, 같은 디자인·같은 크기로 표정 8가지를 4×2 격자 한 장에 그려 줘. 칸 사이 여백 넉넉히, 각 칸 투명 배경.
1) 기본 미소  2) 활짝 기쁨(눈 감고 웃음)  3) 냠냠 먹는 표정(입 벌리고 행복)
4) 어지러움(눈 빙글빙글, 땀방울)  5) 깜짝 놀람(입 O자, 눈 동그랗게)
6) 얄미운 미소(한쪽 눈썹 올리고 씩)  7) 생각 중(턱에 손, 물음표 없이 눈 위로)
8) 졸업모(학사모) 쓰고 자랑스러운 표정
```

```
공통: 노란(#FFD66B) 금속 테두리의 원형 메달, 안쪽은 크림색, 위에 작은 리본. 각 메달 중앙에 아래 상징을 귀엽게 하나씩. 글자 없음, 투명 배경.
```

## ⑤ 게임별 오브젝트 (P2)

각 게임의 데이터 배열에 있는 이모지를 대체합니다. **한 게임당 한 장의 스프라이트 시트**로 뽑는 것을 추천합니다.

### 1차시 — AI야? 아니야? (16개)
```
위 스타일 가이드를 유지해서, 4×4 격자로 사물 16개를 그려 줘. 각각 정사각형 칸 중앙에 크게, 투명 배경, 글자 없음.
[AI가 들어있는 것] 1) 스마트 스피커 2) 번역 앱 화면의 스마트폰(지구본 아이콘) 3) 자율주행 자동차(센서 불빛) 4) 얼굴 인식 카메라 5) 말풍선이 있는 챗봇 화면 6) 로봇 청소기 7) 추천 목록이 뜬 TV 8) 붓을 든 그림 그리는 로봇 팔
[AI가 아닌 것] 9) 선풍기 10) 자전거 11) 연필 12) 주전자 13) 우산 14) 숟가락 15) 축구공 16) 양말
```

### 2차시 — AI 훈련소 (고양이 5, 강아지 5, 바구니 2)
```
위 스타일 가이드를 유지해서, 사진 카드처럼 보이는 동물 초상 10개를 5×2 격자로 그려 줘. 각 카드는 둥근 모서리의 흰 테두리(폴라로이드 느낌), 글자 없음, 투명 배경.
윗줄 고양이 5마리(색·무늬 다르게: 주황 줄무늬, 검정, 흰색, 회색 얼룩, 삼색), 아랫줄 강아지 5마리(품종 다르게: 골든리트리버, 시바, 푸들, 달마시안, 웰시코기).
```
```
같은 스타일로, 라벨 없는 빈 바구니 2개를 나란히 그려 줘. 왼쪽은 분홍 리본, 오른쪽은 파란 리본. 투명 배경.
```

### 3차시 — 골고루 밥상 (데이터 인물 4종)
```
위 스타일 가이드를 유지해서, 동그란 프로필 카드 4개를 한 줄로 그려 줘: 1) 아기 2) 초등학생 어린이 3) 어른 4) 할머니/할아버지.
피부색과 머리 모양을 다양하게, 각 카드 배경색을 노랑·민트·하늘·보라로 다르게. 투명 배경, 글자 없음.
```

### 4차시 — 필터버블 탈출 (영상 썸네일 7종)
```
위 스타일 가이드를 유지해서, 동영상 썸네일처럼 보이는 둥근 사각형 카드 7개를 그려 줘(4+3 격자). 각 카드 오른쪽 아래에 작은 재생 버튼 모양.
1) 게임 컨트롤러(핑크 배경, '추천'용이라 조금 튀게) 2) 책 3) 음표와 헤드폰 4) 축구공 5) 시험관과 비커 6) 팔레트 7) 지구본과 비행기. 글자 없음, 투명 배경.
```

### 5차시 — 개인정보 지킴이 (개인정보 7, 안전 정보 6, 방패 1)
```
위 스타일 가이드를 유지해서, 카드 아이콘 13개를 5×3 격자로 그려 줘(마지막 두 칸 비움). 투명 배경, 글자 없음.
[개인정보 - 빨간 테두리 카드] 1) 집 2) 전화기 3) 셀카 찍는 얼굴 4) 열쇠 5) 이름표와 학교 건물 6) 신용카드 7) 지도 위 위치 핀
[안전한 정보 - 초록 테두리 카드] 8) 팔레트(좋아하는 색) 9) 축구공(취미) 10) 피자 11) 해와 구름(날씨) 12) 책 13) 강아지
```
```
같은 스타일로, 열쇠 문양이 새겨진 반짝이는 하늘색 방패 하나를 크게 그려 줘. 투명 배경.
```

### 6차시 — 진짜? 가짜! 탐정 (장면 카드 10 + 도장 2)
```
위 스타일 가이드를 유지해서, 뉴스/사진 카드 10장면을 5×2 격자로 그려 줘. 각 칸은 '사진'처럼 보이는 둥근 사각형, 글자 없음, 투명 배경.
[가짜] 1) 마이크 든 가수(손가락이 6개!) 2) 정장 입은 사람이 외계인과 악수 3) 급식판에 X표 4) 물컵과 100점 시험지 5) 유명인 얼굴이 뜬 스마트폰 전화
[진짜] 6) 비구름과 우산 일기예보 7) 도서관 건물과 안내판 8) 아기 판다 9) 운동회 만국기와 안내장 10) 박물관 건물과 어린이
```
```
같은 스타일로, 기울어진 고무도장 2개: 빨간 '가짜' 느낌의 X 도장, 초록 '진짜' 느낌의 체크 도장. 글자 없이 기호만. 투명 배경.
```

### 7차시 — 저작권 O/X 달리기 (러너 3포즈 + 문 2)
```
위 스타일 가이드를 유지해서, 달리기 캐릭터(초등학생, 운동복) 3포즈를 한 줄에: 1) 신나게 달리기 2) 두 팔 번쩍 만세 3) 머리 위에 별이 도는 어지러움. 투명 배경, 글자 없음.
```
```
같은 스타일로, 통과할 수 있는 아치형 문 2개: 왼쪽은 초록색 O 모양 문, 오른쪽은 빨간색 X 모양 문. 투명 배경, 글자 없음.
```
