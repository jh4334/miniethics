# 🤖 AI 윤리 미니게임 천국

초등학교 5-6학년을 위한 **인공지능 윤리 12차시 미니게임 학습 앱**입니다.
미니게임천국처럼 짧고 재미있는 게임으로 AI 윤리를 배워요!

- 📱 **설치 없는 웹앱(PWA)**: 안드로이드/iOS 태블릿 브라우저에서 바로 실행, 홈 화면에 추가하면 앱처럼 동작
- 🎮 **12차시 = 12개 미니게임**: 차시를 클리어하면 다음 차시가 열리는 수업 진도형 구조
- 📚 **차시 흐름**: 개념 카드 3장 → 미니게임 → 별점 결과 → 성찰 OX 퀴즈 → 배지 획득
- 🏆 12차시 완주 시 이름이 들어간 **수료증** 발급
- 💾 진행 상황은 기기에 자동 저장 (localStorage)
- 🔊 효과음은 코드로 합성 (사운드 파일 불필요)

## 실행 방법

정적 웹앱이라 서버만 있으면 됩니다.

```bash
# 로컬에서 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

**배포(추천)**: GitHub Pages를 켜면 끝!
저장소 Settings → Pages → 배포 브랜치 선택 → 생성된 주소를 태블릿에서 열기.
학생들에게는 QR코드로 주소를 나눠주면 편합니다.

## 수업에서 쓸 때 알아두기

- **iPad는 '홈 화면에 추가'해서 사용하세요.** Safari 탭으로만 쓰면 일주일 넘게 접속이 없을 때 진행 상황이 지워질 수 있습니다(Safari의 저장소 정책). 홈 화면 앱은 이 제한이 없습니다.
- **교사용 숨은 메뉴**: 타이틀 화면의 로봇을 5번 연속 탭하면 원하는 차시까지 바로 열 수 있습니다. (진행이 지워진 기기, 결석한 학생, 특정 차시부터 시작할 때)
- 안드로이드 뒤로가기 버튼/제스처는 앱 안에서 이전 화면으로 이동합니다(게임 중이면 개념 카드로).
- 게임 중에 다른 앱으로 나가면 게임이 중단되고 '다시 도전' 화면이 뜹니다.
- 진행 상황은 기기(브라우저)마다 따로 저장됩니다. 학생별로 같은 태블릿을 쓰게 하는 것이 좋습니다.
- 로컬 테스트(`http://localhost`)에서는 서비스워커가 등록되지 않습니다. 오프라인 캐시는 https 배포 주소에서만 동작합니다.

## 프로젝트 구조

```
index.html            앱 진입점
css/style.css         전체 스타일 (파스텔톤, 태블릿 터치 최적화)
js/main.js            화면 전환과 차시 흐름 (타이틀→지도→개념→게임→퀴즈→배지)
js/state.js           진행 상황 저장 (localStorage)
js/audio.js           WebAudio 합성 효과음
js/data/lessons.js    12차시 학습 콘텐츠 (개념 카드, 퀴즈, 골든벨 문제은행)
js/data/assets.js     중앙 에셋 맵 (이미지 교체 지점)
js/games/engine.js    미니게임 공통 헬퍼
js/games/g01~g12      12개 미니게임
sw.js                 오프라인 캐시 (PWA)
manifest.webmanifest  홈 화면 설치 정보
```
